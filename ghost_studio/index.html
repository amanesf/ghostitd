ゴーストスタジオ(実験版) — 動画から3Dモデル(M1+M2: 較正+彫刻プレビュー、頂点カラーGLB)

← トップへ

1. ターンテーブル動画を投入

VEO_VIDEO_TO_3D_PLAN.md §3.2のプロンプトVで生成した(または同等の規約の)mp4動画をアップロードしてください。フレーム0=正面(0度)、一定方向に連続回転し、末尾でほぼ1周する動画を前提にしています。

2. フレーム抽出

時間軸で均等にフレームをサンプリングし、ブレ・重複フレームを自動除外します(js/video_frames.js)。

3. シルエット抽出 + ターンテーブル較正 + 特徴追跡による同時較正(Stage B)

各フレームのシルエット・符号付き距離場(js/edt.js)を作り、回転角度・スケール・信頼度を推定します(js/turntable_calib.js)。続けて、瞳・髪の房・服の柄の角等の特徴を隣接フレーム間でNCC追跡し(js/feature_tracks.js)、u_i-cx=s・(x・cosθ_i+z・sinθ_i)の線形最小二乗で3Dアンカー点群化した上で、全トラック残差の交互最小化によりフレーム別θ・cx・ybot・scaleを彫刻結果に依存せず精密化します(VEO_VIDEO_TO_3D_PLAN.md §16「回転ステレオ」方式。彫刻メッシュへの再投影IoU座標降下版だった旧refineCalibrationAnalysisBySynthesisの置き換え)。

青=等速仮定の初期角度、橙=90/270度キーフレーム検出による区分線形補正後(Stage A)、緑=特徴追跡による同時較正後(Stage B)。破線=検出されたキーフレーム位置。

4. 多視点彫刻プレビュー(M2、頂点カラーGLB)

全フレームを同格の直接証拠として扱い、各点にとって最も外側寄りの証拠から始めて隣接する値との差がclusterEpsPx(元動画のpx換算)以内である限り連鎖的に取り込む可変サイズのクラスタを平均して彫刻します(単一連結クラスタ平均、js/multiview_hull.js)。固定個数/固定比率を強制しないため、ツインテール間・帽子の裏側のような狭い可視窓の隙間(少数フレームしか外側と言わない箇所)は少数のまま平均され、無関係な多数派フレームに薄められて消えることがありません(以前のbottom-k固定比率方式で実際に発生した不具合)。一方で広い接線角度域を持つ表面(髪の生え際等)は較正ノイズが複数フレームの平均で打ち消されます。較正(角度・cx・ybot・scaleのフレーム別値)はタブ3で特徴追跡(Stage B、js/feature_tracks.js)により彫刻結果に依存せず精密化済みのものをそのまま使い、等値面近傍だけを画像の実ピクセル相当の解像度まで細かく再計算するcoarse-to-fine方式です。彫刻後は0/90/180/270度の実測フレームとの再投影IoUを表示し、目視でモデルを回転させなくても基準4方向での忠実度を確認できるようにしています。UVチャート展開・複数フレーム加重合成ベイク(M3)は行わないため、テクスチャは無く、法線ベースの簡易な頂点カラーで陰影を付けたプレビューになります。
